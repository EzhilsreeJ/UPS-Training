## How to Run

1. Open the `Day-19` folder in VS Code.
2. Open `index.html` in a browser or using Live Server.
3. Open the browser Developer Tools using `F12`.
4. Select the **Console** tab to view the JavaScript output.
5. To run another practical through the HTML page, change the script reference in `index.html` to the required JavaScript filename.

You can also run each JavaScript file individually using Node.js:

```bash
node variables.js
node datatypes.js
node operators.js
node programs.js
```
