# Day 25 – Student DTO and Entity Mapping using MapStruct

## Overview

Developed a Student Management REST API using Spring Boot and MapStruct. The application demonstrates how to convert data between a Student Entity and Student DTO, save the entity in a MySQL database, and return the saved student as a DTO.

- Spring Boot Project Setup
- Layered Architecture
- Entity and DTO Creation
- Data Transfer Objects (DTO)
- Entity-to-DTO Mapping
- DTO-to-Entity Mapping
- MapStruct Mapper Interface
- MapStruct Annotation Processing
- Spring Data JPA and JpaRepository
- Service and Controller Layers
- MySQL Database Connectivity
- REST API Development
- POST Request Testing using Postman

## Application Architecture

| Layer | Responsibility |
|---|---|
| Entity | Represents the Student database table |
| DTO | Carries student data between the client and application |
| Mapper | Converts Student Entity to Student DTO and vice versa |
| Repository | Performs database operations using JpaRepository |
| Service | Handles mapping and student-saving logic |
| Controller | Exposes the REST API endpoint |

## Student Entity and DTO

Both classes contain the following fields:

| Field | Data Type |
|---|---|
| id | Long |
| name | String |
| email | String |

The database generates the student ID automatically.

## MapStruct Mapping

The `StudentMapper` interface uses `@Mapper(componentModel = "spring")` so MapStruct generates an implementation that Spring can inject as a bean.

- `toEntity()` converts the incoming Student DTO into a Student Entity.
- `toDto()` converts the saved Student Entity into a Student DTO.

The MapStruct annotation processor is configured in `pom.xml` to generate the mapper implementation during compilation.

## REST API Endpoint

**Method:** POST  
**URL:** `http://localhost:8080/api/students`

### Example JSON Request

```json
{
    "name": "Ezhil",
    "email": "ezhil@gmail.com"
}
```

### Expected Response

```json
{
    "id": 1,
    "name": "Ezhil",
    "email": "ezhil@gmail.com"
}
```

The ID is generated by the database. The endpoint returns HTTP `201 Created` after successfully saving the student.

## Database Configuration

**Database:** `studentmapperdb`

Create the database in MySQL:

```sql
CREATE DATABASE studentmapperdb;
```

Update the MySQL username and password in `StudentMapper/src/main/resources/application.properties` before running the application.

## How to Run

1. Open the `StudentMapper` folder in IntelliJ IDEA or another Java IDE.
2. Make sure JDK 21 is configured.
3. Start the MySQL server and create the `studentmapperdb` database.
4. Update the MySQL credentials in `application.properties`.
5. Run `StudentMapperApplication.java`.
6. Send a POST request to `http://localhost:8080/api/students` using Postman.

Alternatively, from the `StudentMapper` folder, run:

```bash
./mvnw spring-boot:run
```

On Windows:

```bat
mvnw.cmd spring-boot:run
```
