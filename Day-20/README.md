## Project Overview

Code Architect is a web-based software development platform designed to help users plan, build, test and deploy full-stack applications from a single workspace. It brings project planning, AI-assisted project creation, GitHub integration and cloud deployment features together in one organized interface.

## Main Modules

### 1. Login Page
- Sign in using email and password.
- Login options through GitHub and Google accounts.
- Sign-up option for new users.

### 2. Dashboard
- Displays total projects, AI-generated applications, connected GitHub repositories and live deployments.
- Provides quick actions to create projects, connect GitHub and deploy to Vercel.
- Shows integration status, recent activity, recent projects and deployment success rate.

### 3. Create Project
A guided workflow for creating an application:
- Project details
- Configuration
- Review and generation
- Debugging
- Generated output

Users can enter a project name, description and key features, then select an application type:
- Web Application
- Mobile Application
- API / Backend

The architecture options include:
- Monolithic
- Microservices

An AI Project Assistant helps users prepare project ideas, descriptions and feature lists.

### 4. GitHub Integration
- Connect a GitHub account.
- Link existing repositories or create new repositories.
- Manage branches.
- Review commit history.
- View GitHub activity logs.

### 5. Vercel Deployment
- Select a project for deployment.
- Configure build commands and output directories.
- Manage environment variables.
- Preview the deployed application.
- Monitor deployment history and traffic analytics.

## Project Navigation
