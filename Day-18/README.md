# Day 18 – CSS Media Queries, Filters and Animation

## Topics Covered
- CSS Media Queries and responsive design
- CSS image filters
- CSS animations and `@keyframes`
- Animation duration, percentages and iteration count
- Relative and absolute positioning
- Personal portfolio using HTML, CSS and JavaScript

## Practical Tasks

### Task 1 – Responsive Media Queries
Created a responsive page that changes its background, text color and layout according to the screen width.

**File:** `01-Media-Queries/index.html`

### Task 2 – Image Filters
Displayed an image gallery demonstrating grayscale, blur, brightness, contrast, saturate, sepia, invert and drop-shadow filters.

**File:** `02-CSS-Filters/index.html`

### Task 3 – CSS Animation
Created an animated square that moves between different positions while changing its background color.

**File:** `03-CSS-Animation/index.html`

### Task 4 – Personal Portfolio
Created a personal portfolio with an introduction, about section, technical skills, project interests and a contact form. The page uses responsive navigation, CSS transitions, keyframe animation and JavaScript form interaction.

**Files:**
- `04-Portfolio/index.html`
- `04-Portfolio/style.css`
- `04-Portfolio/script.js`

## How to Run
1. Open the `Day-18` folder in VS Code.
2. Open any task folder.
3. Run its `index.html` file in a browser or with VS Code Live Server.
4. The portfolio's HTML, CSS and JavaScript files must remain in the same folder.
