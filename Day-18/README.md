## Task 1 – Responsive Media Queries

**Objective:** Create a responsive webpage that changes its background, text color and layout based on screen width.

**Implementation:**
- Desktop: Default background and heading styles.
- Mobile (up to 600px): Light green background and different heading color.
- Tablet (601px–992px): Light yellow background and different heading color.
- Used CSS media queries to apply screen-specific styles.

**Source Code:** [View Media Queries](01-Media-Queries/index.html)

## Task 2 – CSS Image Filters

**Objective:** Understand and apply different CSS filters to images.

**Filters Implemented:**

- Sepia

**Implementation:** Created an image gallery demonstrating different filter effects using CSS.

**Source Code:** [View CSS Filters](02-CSS-Filters/index.html)

## Task 3 – CSS Animation

**Objective:** Create an animated square using CSS animations and `@keyframes`.

**Implementation:**
- Created a square element using CSS.
- Used absolute positioning to move the square.
- Applied different background colors at animation stages.
- Used keyframes at 0%, 25%, 50%, 75% and 100%.
- Set animation duration to 4 seconds with infinite iteration.

**Source Code:** [View CSS Animation](03-CSS-Animation/index.html)
